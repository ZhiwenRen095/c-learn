# C Language Learning Project

C 语言学习项目，包含基础练习和进阶学习笔记。

## 项目结构

```
C-learn/
├── helloworld.c           # Hello World 基础程序
├── c&pointer/             # C 与指针学习笔记
│   └── chapter1/          # 第一章练习
│       └── rearrange_characters.c
└── .gitignore             # Git 忽略文件配置
```

## 编译运行

```bash
# 编译单个文件
gcc helloworld.c -o helloworld

# 运行
./helloworld
```

## 学习内容

- **基础语法**: Hello World 程序
- **指针深入**: C 与指针专题学习
